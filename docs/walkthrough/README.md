# Atelier walkthrough

Screenshots of the app as it runs today (the interface still says CreativePhotoEditor). Captured from the local dev server at `http://localhost:3000`.

| File | What it shows |
|------|----------------|
| `01-landing.png` | Landing page: headline, start button, and the four feature cards. |
| `02-editor.png` | Editor on first open. Top bar, tool rail, canvas, and empty Layers panel. |
| `03-new-document.png` | New document dialog: name, size, presets, background. |
| `04-workspace.png` | Workspace after creating a document, before any layers. |
| `05-layers.png` | A rectangle layer on the canvas, with opacity, blend, mask, and the layer row. |
| `06-settings.png` | Settings: tooltips, tooltip delay, canvas fit, aspect lock, pixel snap, guides, rulers, edge snap. |
| `07-export.png` | Export as a single flattened image: PNG, JPG, or WebP, scale, and background. |
| `08-export-layers.png` | Export each layer as its own file, including trim and visible-only options. |
| `09-history.png` | History panel, with the base state and the added rectangle. |
| `10-brush-options.png` | Brush tool options: color, size, opacity, hardness, flow, spacing, and brush tips. |
| `11-transform.png` | Transform tool: aspect lock, fit canvas, and the handles on the shape. |
| `12-adjust-filters.png` | Adjust & Filters: exposure through gamma, plus the filter buttons. |
| `13-smart-tools.png` | Smart tools: Remove background and Select subject. |
| `14-auto-layers.png` | Auto-Layers / Slice dialog: detect regions or an even grid. |
| `15-text.png` | A text layer on the rectangle, with the text options bar (font, size, alignment, color). |

Shots `12`–`14` are framed on the open panel or dialog, so the top bar sits above the frame.
