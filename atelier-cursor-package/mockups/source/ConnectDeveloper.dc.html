Instructions for your developer or AI
# Connect this game to Atelier

Atelier (the art editor) writes sprites into Bap/Bap/Art/Generated/.
Do not edit files in that folder. Atelier overwrites them on export.

1. Add the AtelierKit Swift package:
   https://github.com/nathanokh1/AtelierKit  (version 1.0)
2. Draw sprites through the generated names, for example:
   let tex = Sprites.paddle.texture(upgrade: "Lv3", tag: "idle", frame: 2)
   AtelierKit returns an SKTexture with nearest-neighbor filtering.
3. Colors come from Palette.bapRetro16 in Generated/Palette.swift.
   Replace hand-written color values with these.
4. Create Bap/Bap/Art/atelier-handshake.json with:
   { "game": "Bap", "reader": "AtelierKit", "version": 1 }
   Atelier looks for this file to confirm the game is connected.
